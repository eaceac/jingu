# Garden dashboard

The local password-protected dashboard shows the learner's garden, patch name, streak and daily practice. Group summaries live under “Today in the garden”; the underlying data model supports multiple user IDs, but the current interface is a personal installation.

The illustrated landscape is `apps/dashboard/garden-oil-v1.png`, generated in text-to-image mode. Wooden beds and plants are separate SVG artwork driven by deterministic progress. Patch naming uses the same authenticated practice queue as the conversation.

Artwork brief: a dreamy traditional oil painting on linen, visible impasto, soft meadow, distant wooded hills, lilac flowers at the edges, lavender and peach evening sky. Keep the center clear for independently rendered garden boxes. No text, people, logos or painted-in boxes.
