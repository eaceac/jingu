# Product decisions

- Name: Jingu. Korean first, language-pack architecture for future languages.
- Current interface: a local password-protected website for one learner.
- Dashboard-first layout with an oil-painted landscape and distinct garden boxes/plants.
- AI handles conversation and semantic grading only; application code owns vocabulary selection, scheduling and rewards.
- Backend-owned model credentials; no keys in the browser or repository.
- Default five words, configurable direction and transliteration.
- Daily streak with one-day partial-practice hold; permanent garden growth for completed days.
- Deterministic SRS stays in the application rather than a separate service.
- Additional languages, users and hosted access remain future work.
