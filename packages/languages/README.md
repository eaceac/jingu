# Language packs

`koreanStarterPack` contains 50 original draft everyday Korean senses, examples, and reference forms. These are seed data for development, **not an educator-reviewed curriculum**. Review sense definitions, naturalness, inflections, and politeness before the personal alpha.

`acceptedForms` helps the semantic grader understand ordinary forms. It is not a whitelist: valid inflections, minor typos, and romanizations allowed by the learner's settings still need contextual grading. Register notes can constrain a prompt; for example an informal greeting does not satisfy a request for polite speech.

Stable sense IDs identify meanings rather than surface strings. `rank` is deterministic introduction order. Neither rank nor the pack performs scheduling. `spanishFixturePack` is a one-sense cross-language fixture, not a second complete course.
